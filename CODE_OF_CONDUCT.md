# Code of Conduct

## Our standard

Be respectful and constructive. Disagreement about code, architecture, or
approach is normal and welcome — personal attacks, harassment, and bad-faith
engagement are not.

## Scope

This applies to interactions in this repository's issues, pull requests,
and any other project space.

## Reporting

If something in this project's spaces made you feel unwelcome or unsafe,
contact the repository owner directly (see `SECURITY.md` for the same
reporting channel used for security issues).

## Enforcement

The repository owner is responsible for clarifying and enforcing these
standards, and may remove, edit, or reject contributions or interactions
that don't align with this Code of Conduct.
